# CW-142 – Sprint Retrospective

# Propósito

Registrar las lecciones aprendidas y oportunidades de mejora identificadas durante la ejecución de cada Sprint.

Es un documento vivo administrado por el CW PMO y constituye la base para la mejora continua del proceso de desarrollo.

---

# Objetivos

- Registrar las lecciones aprendidas.
- Identificar oportunidades de mejora.
- Registrar acuerdos de mejora continua.
- Evitar repetir errores en Sprint futuros.
- Servir como entrada del comando `review`.

---

# Reglas

- Cada Sprint deberá registrar una retrospectiva.
- No se eliminarán registros históricos.
- Las acciones acordadas deberán trasladarse al Product Backlog cuando corresponda.

---

# Integración con el PMO

Este documento es utilizado por:

- review
- start
- close

para incorporar la experiencia acumulada del proyecto al siguiente Sprint.
