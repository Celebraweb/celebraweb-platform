# CW-143 – Open Issues

# Propósito

Registrar de forma centralizada los incidentes, bloqueos, dependencias y situaciones pendientes que afectan la evolución del proyecto.

Es un documento vivo administrado por el CW PMO.

---

# Objetivos

- Centralizar los problemas abiertos del proyecto.
- Dar seguimiento hasta su resolución.
- Facilitar la planificación de los Sprint.
- Servir como entrada del comando `review`.

---

# Estados

| Estado | Descripción |
|---------|-------------|
| OPEN | Pendiente |
| IN PROGRESS | En análisis o resolución |
| RESOLVED | Resuelto |
| CLOSED | Cerrado |

---

# Reglas

- Todo Issue deberá registrarse.
- Ningún Issue se eliminará; únicamente cambiará de estado.
- Todo Issue resuelto deberá conservar su trazabilidad.

---

# Integración con el PMO

Este documento es utilizado por:

- review
- start
- close

para identificar los problemas que permanecen abiertos entre Sprint.
