# CW-140 – Product Backlog

# Propósito

El Product Backlog constituye el registro oficial y permanente de todo el trabajo pendiente del proyecto CelebraWeb.

Es un documento vivo que evoluciona durante todo el ciclo de vida del producto y es administrado por el CW PMO.

No pertenece a un Sprint específico.

Los Sprint consumen elementos del Product Backlog y registran su resultado.

---

# Objetivos

- Centralizar el trabajo pendiente del producto.
- Evitar la pérdida de contexto entre Sprint.
- Mantener la trazabilidad del roadmap.
- Servir como entrada oficial del comando `review`.
- Servir como referencia para la planificación de Sprint.

# Reglas

- Todo trabajo pendiente deberá registrarse en este documento.
- Ningún Sprint iniciará sin revisar este Backlog.
- Ningún elemento deberá eliminarse; únicamente cambiará su estado.
- Todo elemento finalizado deberá mantener su trazabilidad histórica.

---

# Integración con el PMO

Este documento es utilizado por:

- review
- start
- close

para mantener la continuidad del proyecto entre Sprint.
